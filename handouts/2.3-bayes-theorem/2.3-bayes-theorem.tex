\prob Imagine a test designed to detect a disease with the following characteristics:
\begin{itemize}
\item $1\%$ of the population has the disease.
\item If a person has the disease, the test will return a positive $90\%$ of the time.
\item If a person does not have the disease, the test will still return a positive $9\%$ of the time.
\end{itemize}
A patient with no symptoms takes the test and it comes back positive. What is the probability that they actually have the disease?

\prob (Example 2.3.4) Three different machines $M_1$, $M_2$, and $M_3$ were used for producing a large batch of similar manufactured items. Suppose that:
\begin{itemize}
\item $20\%$ of the items were produced by machine $M_1$.
\item $30\%$ of the items were produced by machine $M_2$.
\item $50\%$ of the items were produced by machine $M_3$.
\end{itemize}
Suppose further that:
\begin{itemize}
\item $1\%$ of the items produced by machine $M_1$ are defective.
\item $2\%$ of the items produced by machine $M_2$ are defective.
\item $3\%$ of the items produced by machine $M_3$ are defective.
\end{itemize}
Finally, suppose that one item is selected at random from the entire batch and it is
found to be defective. Determine the probability that this item was produced
by machine $M_2$.

\prob Suppose that a box contains one fair coin and one coin with a head on each side. Suppose also that one coin is selected at random.

\medskip
\begin{enumerate}
\item Suppose that the coin is tossed once and a head is obtained. Determine the probability that the coin is the fair coin.
\item Suppose that the coin is tossed a second time and a head is obtained. Determine the new probability that the coin is the fair coin.
\end{enumerate}
